Реализуйте класс Employee, описывающий сотрудника: имя, должность и зарплата. Все поля должны быть доступны только для чтения снаружи класса (изменяться — только через метод Promote).

Часть 1. Перегруженные конструкторы

Класс должен иметь ровно один "полный" конструктор, который содержит всю проверку входных данных, и три более простых конструктора, каждый из которых обязан делегировать вызов через this(...), а не повторять проверки самостоятельно.

Employee(string name, string position, decimal salary) — основной конструктор. Бросает ArgumentException, если name или position пусты, состоят только из пробелов, либо если salary отрицательна.Employee(string name, string position) — зарплата принимается равной константе DefaultSalary = 500m.Employee(string name) — должность принимается равной константе DefaultPosition = "Стажёр", зарплата — DefaultSalary.Employee() — имя принимается равным константе DefaultName = "Без имени", остальное — как в конструкторе выше.

Часть 2. Перегруженный метод Promote

Реализуйте четыре перегрузки метода Promote, описывающего повышение сотрудника. Новая логика существует только в одной из них — остальные три должны вызывать друг друга, а не дублировать вычисления.

void Promote() — повышает зарплату на стандартный процент, заданный константой DefaultRaisePercent = 10m. Должен вызывать перегрузку с параметром, а не повторять формулу.void Promote(decimal raisePercent) — повышает текущую зарплату на указанный процент (Salary += Salary * raisePercent / 100). Бросает ArgumentException, если raisePercent не положителен.void Promote(string newPosition) — меняет должность без изменения зарплаты. Бросает ArgumentException, если newPosition пуста или состоит только из пробелов.void Promote(string newPosition, decimal raisePercent) — меняет должность и повышает зарплату одновременно, вызывая обе предыдущие перегрузки.

Дополнительно переопределите ToString(), чтобы он возвращал строку вида "Имя, Должность, Зарплата", например "Иванов И.И., Разработчик, 1500". Это понадобится для демонстрации результата на занятии.

Ограничения

Запрещено использовать значения параметров по умолчанию (string position = "Стажёр") в каких-либо методах или конструкторах. Все варианты обязаны быть реализованы именно как отдельные перегрузки — это и есть предмет проверки в этой контрольной точке.

Критерии оценивания

Контрольная точка оценивается по шкале 0–1 балл.

1 балл — результат продемонстрирован во время занятия, без нарушения дедлайна, установленного преподавателем, и дан верный ответ на 1 вопрос по теме (вопрос преподаватель выбирает из опубликованного банка вопросов).0 баллов — результат продемонстрирован с нарушением дедлайна, независимо от корректности реализации.

Вариант 1. Playlist (плейлист)
Класс Playlist хранит список названий треков.
void Add(string title) — добавляет трек в конец списка.
Индексатор this[int position] — доступен на чтение и запись, возвращает/задаёт название трека по позиции. Бросает ArgumentOutOfRangeException, если позиция выходит за пределы списка.
Индексатор this[string title] — только на чтение, возвращает позицию трека с таким названием или -1, если трек не найден.
Переопределите ToString(), чтобы вывести треки через запятую с указанием их позиций, например: "0: Track A, 1: Track B".
