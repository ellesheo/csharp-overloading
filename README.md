# Перегрузка в C#

Учебные работы по теме «Перегрузка» — контрольные точки по дисциплине.

## Состав

| Папка | Тема | Класс |
|---|---|---|
| [KT1-Employee](KT1-Employee) | КТ №1 — перегрузка методов и конструкторов | `Employee` |
| [KT2-Playlist](KT2-Playlist) | КТ №2 — перегрузка индексаторов | `Playlist` |

## КТ №1 — Employee

Четыре конструктора, выстроенных в цепочку через `this(...)`: вся проверка данных и присваивание свойств находятся только в полном конструкторе с тремя параметрами, остальные три подставляют недостающие значения из констант.

Четыре перегрузки метода `Promote`: формула повышения зарплаты написана один раз, в перегрузке с параметром `decimal`. Перегрузка без параметров передаёт ей константу, перегрузка с двумя параметрами вызывает две предыдущие.

## КТ №2 — Playlist

Два перегруженных индексатора, различающихся типом параметра:

- `this[int position]` — чтение и запись трека по позиции, бросает `ArgumentOutOfRangeException` при выходе за границы;
- `this[string title]` — только чтение, возвращает позицию трека или `-1`, если трек не найден.

## Запуск

```bash
cd KT1-Employee
dotnet run
```

Требуется .NET 10 SDK.
